# Hypothetical reviews and workspace evidence (#441)

Scope resolves explicit files/projects, supplied evidence and bound continuation references before deciding whether a review needs current workspace sources. Indefinite product references such as “a news site” or “a typical application” are generic advice, even if their artifact is a review. Generic reviews have no workspace tool or command authority.

Explicit “this website”, “our dashboard”, file inspection and named sibling projects remain workspace work. Supplied specification content stays in the original message; a hypothetical review does not read an unrelated open project to invent grounding. Ambiguous existing-code questions retain the unverified state rather than automatically becoming generic.

Production-capture tests check scope, tool admission and actual model input for hypothetical, supplied-specification and explicit workspace/sibling cases. They do not claim live model correctness.
