# Short implementation requests (#434)

Direct imperatives such as “Add pagination”, “Remove the debug banner” and “Save this as README.md” retain edit intent without requiring a known feature noun. The router and resolver share the same direct-edit predicate, so a cold or unavailable semantic resolver cannot silently turn an explicit operation into an explanation.

This interpretation does not grant authority independently: Ask mode, explicit effect prohibitions, project resolution and the existing tool gateway still apply. Missing projects block workspace execution. Quoted content, arithmetic, conversational subject changes and self-contained chat examples remain read-only. Ambiguous non-imperative wording still uses the conservative resolver fallback.

Production-capture regressions cover the seven reported forms with and without a project, available mutation tools, explicit no-edit constraints and Ask mode. These deterministic checks do not certify live model quality or installed-platform behavior.
