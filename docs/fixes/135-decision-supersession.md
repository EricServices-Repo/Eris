# #135 — scoped declarations, corrections and disputes

A bounded deterministic DecisionIndex projects explicit user declarations with source ID/span, exact normalized subject, main-recorded project scope and active/superseded/disputed state. It recognizes a restricted Remember/Decision/Correction/Actually grammar; quoted, fenced, negated and uncertain lines are not promoted. Assistant suggestions never supersede user declarations. Explicit same-subject/same-scope corrections suppress prior sources; conflicting declarations without correction remain disputed. Forgetting the correcting source does not silently reactivate its superseded predecessor. Identical repeated declarations retain distinct source identity for recent-source deduplication.

Main records resolved scope on the current canonical user source after task intake, preserving message identity, sequence and content while increasing its metadata revision. Workspace worker projections retain that scope. Old unscoped sources remain ordinary historical evidence for a project turn, rather than being guessed into its current-decision registry. No declaration expands task authority. Decisions remain evidence; the current user request and task contract prevail.

The index is capped at 512 subjects/four provenance records each and charges its estimated bytes to the cache envelope. It is assembled during install and incrementally extended on append, not rescanned in full per selection. Decision IDs include source span, value, scope and state; dispatch revalidation rejects obsolete projections.

Validation: `npx vitest run tests/context-decisions.test.ts tests/context-memory.test.ts tests/chat-stream.test.ts`: explicit corrections, ambiguity, independent projects, exclusions, quotation/negation, minimum-budget compatibility, canonical recent coverage and durable scope metadata. No model-assisted extraction or live provider acceptance is claimed. Recognition is intentionally narrow; unsupported prose remains unverified raw evidence.
