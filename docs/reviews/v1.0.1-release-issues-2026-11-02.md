## Completion discipline

Every item needs an accountable person, scoped implementation/PR or source review, regression/procedure, exact source/lock/runtime/model/artifact identity, fixture/corpus hash, processed/total/pass/fail/skipped, evidence stage and limitations. Preserve working safeguards rather than rewriting them merely to close a checkbox.

Conditional deferrals require enforced denial at UI/IPC/tools/persisted jobs/APIs and matching documentation. Core authority/privacy/data integrity/coding/cancellation and strict 1.x certification are mandatory. Candidate changes invalidate affected evidence; package version equality does not establish source identity.
