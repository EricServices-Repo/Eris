# EricServic.es API stubs

Reference PHP stubs for endpoints on www.ericservic.es.

- `api/eris/v1/cloud-agents/`: the fleet API for the **retired** Cloud Agent worker (see [the Cloud Agent README](../README.md)). It is not used by the desktop app.
- `api/eris/v1/usage.php`: profile usage sync, which the desktop still calls. The request contract is in [Account sync](../../docs/PROFILE-SYNC.md#usage-sync).

These are stubs. They are not the production implementation, and they don't show how the live site is configured.
